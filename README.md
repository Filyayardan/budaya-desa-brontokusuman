## 🛠️ Tech Stack

**Frontend**
* Framework: React.js / Next.js
* Styling: Tailwind CSS
* State Management: Zustand

**Backend & Database**
* Runtime/Framework: Node.js (Express.js / NestJS)
* Database: PostgreSQL (ORM: Prisma / TypeORM)
* Caching & Auth: Redis, JWT

**DevOps & Tools**
* Deployment: Vercel (Client), Railway / AWS EC2 (Server)
* Version Control: Git & GitHub Projects (Kanban)

## ✨ Fitur Utama
* **Autentikasi & Otorisasi Aman:** Login multi-role menggunakan token JWT yang tersimpan di HttpOnly Cookies.
* **Manajemen Data Real-time:** Dashboard analitik interaktif dengan filter dinamis.
* **Payment Gateway / File Storage:** Integrasi webhook pembayaran otomatis dan integrasi cloud bucket storage.
